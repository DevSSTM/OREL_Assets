1-Minute Setup Instructions:

  1. Create or open your Google Spreadsheet (e.g., named OREL Asset Registry).
  2. In Google Sheets menu, click Extensions > Apps Script.
  3. Delete any code in the editor, and paste the code below.
  4. Click the blue Deploy button > New deployment.
  5. Choose type Web app, set Execute as: Me, and Who has access: Anyone.
  6. Click Deploy, authorize access, copy the Web App URL, and paste it above!
